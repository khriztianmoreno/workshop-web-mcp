# WebMCP vs. MCP de servidor

**Tiempo:** ~30 s · **Reloj:** 5:10 → 5:40

**Guion:**
No compiten, se complementan.
**WebMCP** cuando el usuario está en la página: su sesión, la UI que ya existe y el usuario viendo lo que hace el agente. A cambio, necesita la página abierta.
**MCP de servidor** cuando no hay navegador: agentes en segundo plano, backends, automatización. [pausa]
Regla rápida: si la acción tiene sentido con un humano mirando la pantalla, es candidata a WebMCP.
